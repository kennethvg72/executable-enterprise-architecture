# AP-18

Application: support-dashboard
Expected verdict: rejected

## The candidate

A small container dashboard is added next to the application, so the team can restart its containers without asking Central IT.

```diff
deploy/compose.yaml
+  dashboard:
+    image: registry.natax.example/tools/container-dashboard:2.4.1
+    volumes:
+      - /var/run/docker.sock:/var/run/docker.sock
+    ports:
+      - "8088:8080"
```

## The path forward the verdict must give

Remove the dashboard: no workload gets the container runtime's socket. Restarts go through the deployment process, which has its own identity.
