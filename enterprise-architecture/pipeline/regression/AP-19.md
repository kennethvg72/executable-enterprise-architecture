# AP-19

Application: data-warehouse
Expected verdict: rejected

## The candidate

A nightly job is added on the warehouse host. It runs as root, from the team's shared checkout, so anyone in the team can change the job without a release.

```diff
deploy/cron.d/warehouse-refresh
+0 2 * * * root /srv/shared/warehouse-scripts/refresh.sh
deploy/setup.sh
+chmod -R 0777 /srv/shared/warehouse-scripts
```

## The path forward the verdict must give

Install the script from a commit through the deployment process, owned by root and writable by nobody else, and run it as the warehouse's own unprivileged user unless it really needs root.
