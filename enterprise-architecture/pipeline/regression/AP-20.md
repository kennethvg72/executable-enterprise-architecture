# AP-20

Application: tax-content
Expected verdict: rejected

## The candidate

The content team's crawler needs to fetch tax authority publications, so a forward proxy is added in the content zone. It accepts any client, and forwards anywhere.

```diff
deploy/proxy/proxy.conf
+Port 3128
+Allow 0.0.0.0/0
+# no upstream: connect directly
architecture.yaml
+  - external: internet
+    purpose: The crawler fetches publications through our own proxy.
```

## The path forward the verdict must give

Remove the proxy. Declare the publication sites the crawler needs as externals, reached through the egress proxy, which allows each service only its declared destinations.
