# OK-01: A fix is its own reason

Application: rejection-triage
Expected verdict: approved
Counterpart of: AP-15

## The candidate

A fix with a reason that names what it remedies. Its purpose is the one already recorded in the requirement it restores (R-004), so the Governance Agent must accept the reason, not reject it as "not saying what it is for".

```diff
docs/requirements.md
+| R-013 | 2026-10-22 | Claims are released again after 24 hours. | To remedy the bug introduced by version 2.3.1, which stopped releasing them (R-004). | test/claims.test.ts |
src/claims.ts
-  WHERE claimed_at < now() - interval '24 hours' AND status = 'claimed'
+  WHERE claimed_at < now() - interval '24 hours' AND status IN ('claimed', 'contacting')
```

## What the verdict must say

That the reason is valid: it names what broke (version 2.3.1) and the purpose it restores.
