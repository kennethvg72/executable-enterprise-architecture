# OK-03: Exact destinations, through the egress proxy

Application: notification-service
Expected verdict: approved
Counterpart of: AP-10

## The candidate

The email provider adds a second regional endpoint. Both exact hostnames, as the provider documents them, are declared, and reached through the egress proxy.

```diff
enterprise-architecture/landscape/landscape.yaml
     fqdn: api.mail-provider.example
+  email-provider-eu:
+    fqdn: eu.api.mail-provider.example
+    port: 443
+    consumers: [notification-service]
architecture.yaml
+  - external: email-provider-eu
+    critical: false
+    purpose: The provider's EU endpoint, for customers whose mail is routed there.
```

## What the verdict must say

That each destination is exact, declared on both sides and reached through the egress proxy: compliant.
